# 农历日历 · iPhone Scripting

适用于 iPhone **Scripting** 的农历与倒班日历。提供完整月历首页、小号今日日卡、中号两周日历和大号月历，支持农历、传统节日、24节气、中国大陆休班标记及彩色班次。支持日夜外观，每次打开日历首页自动联网刷新假日数据。

## 一键导入

[点击一键导入到 Scripting](https://scripting.fun/import_scripts?urls=["https%3A%2F%2Fgithub.com%2FWangsc1%2Fcalendar"])

在 iPhone 上打开链接，按提示导入。需要先安装 Scripting。

## 安装与使用

1. 在 iPhone 打开导入链接，按提示导入。
2. 在 Scripting 运行 `calendar`，即可打开日历首页。
3. 主屏幕长按 → 添加 Scripting 小组件 → 编辑小组件 → 选择 `calendar`，参数留空。
4. 可选择小号、中号或大号。建议使用系统原色／全彩外观；系统着色模式可能改变配色。

也可创建脚本项目并复制完整仓库源码。项目根目录应直接包含 `script.json`、`index.tsx`、`widget.tsx`，同时保留 `vendor/`、`licenses/` 等依赖文件，无需 npm 构建。

## 日历首页

- 顶部显示今天的公历日期，点击可回到本月并选中今天。
- 月份两侧箭头切换上一月／下一月；在星期栏和日期区域左右滑动也可翻月：左滑下一月，右滑上一月。
- 月历为七列六行，包含前后月日期；星期顺序跟随「每周首日」设置。
- 每格显示公历日期及农历、节日或节气。今天使用红色标记；周末和其他月份日期显示淡色。
- 点击日期，底部显示所选日期的完整公历、干支生肖年、农历月日及相关节日、节气。
- 首页及设置页跟随系统浅色／深色外观。

## 右上角设置

点击首页右上角「⋯」打开设置，版本号显示在「设置」标题右侧。

| 设置 | 功能 |
|---|---|
| 每周首日 | 周一至周日任选，默认周一；影响首页和中、大号小组件的排列 |
| 休班显示 | 蓝色「休」／橙色「班」，或对应颜色的小圆点 |
| 今日显示 | 圆形／圆角方形红底；用于首页及中、大号小组件 |
| 倒班设置 | 新建、编辑、左滑删除班次；点「编辑排序」后拖动，每班一天按列表顺序循环 |
| 预览组件 | 打开 Scripting 自带预览界面，可在预览中选择尺寸和主题 |
| 刷新缓存 | 主动获取相关年份的休班安排并请求刷新小组件 |

设置保存在当前脚本的私有 Storage，不影响其他脚本。设置变化会请求桌面小组件刷新，实际时机由 iOS 决定。

## 倒班：按班次排序每天循环

入口：右上角「⋯」→「倒班设置」。默认关闭，提供 **白班（蓝）→上夜（红）→下夜（橙）→休息（绿）** 四种班次；尚未保存设置时不生成实际排班。

1. **设置班次**：修改名称，或点「新建班次」增加一项。名称须唯一、1—4字，最多12种；新增项需填写名称后才能保存。
2. **设置颜色与样式**：「普通／透明」直接显示当前颜色的标签预览，选中项用绿色圆角外框标示。点击右侧箭头展开色板，再点色块选色；各班次色板独立开合，默认收起。原32色与六个旧色合并为 **38色色板**，选中色块显示对勾，不改变已保存的原始色值。
3. **编辑排序**：点「班次设置」右侧的「编辑排序」，用原生拖动把手调整顺序，再点「完成」。宿主缺少自定义编辑接口时回退为系统「编辑／完成」。**每个班次一天，按列表从上到下循环**；新增班次会加入末尾，不再另设循环位置或手动基准日期。
4. **开启并返回**：开启「倒班显示」，返回上一页时自动校验、保存并请求刷新组件，无需额外点击保存。首次成功保存时，以**保存当天（北京时间）为第一班**；首页与组件按同一规则显示。

班次设置下方说明：**班次循环按照以上排序从当日开始循环**。

### 起算日期与保存规则

- 首次设置，以及旧版独立循环首次通过新设置页保存时，从保存当天的第一班重新起算。旧版班次名称、颜色和样式保留；原来的重复循环、手选日期和循环位置会转换为当前列表每日循环规则。只更新脚本或读取数据不会自动改写排班。
- 此后，**调整顺序、增加或删除班次**后返回保存，会从保存当天重新起算。只比较最终列表：拖动后又拖回原顺序，或新建后又删除回到原列表，不会因此重新起算。
- **改名称、改颜色、改普通／透明样式、切换倒班显示或仅打开查看**，不重置已经确定的起算日期。没有实际变化时不重复写入或请求刷新。
- 在班次行**向左滑动**后点删除，再在居中确认弹窗选择删除或取消。最后一个班次不能删除；确认删除只修改草稿，返回保存后才应用。
- 空名称、重复名称等无效配置不保存；保存失败时保留原排班，草稿在本次打开期间保留，可重新进入设置修正或重试。读取失败或坏配置不会自动改写存储。
- 起算日前按同一循环倒推，跨月、跨年、闰日均按自然日连续计算，不受旅行时区或夏令时影响。
- 自动保存依赖宿主的页面消失回调，无法保证强制退出或进程被杀前保存。小组件刷新只是请求，实际时机由 iOS 决定。

### 班次显示

- 首页日期格与日期详情显示班次；小号组件在大日期旁显示标签，中、大号在各日期格内显示标签，锁屏文字附带班次名称。
- 「普通」使用实色底白字；「透明」使用浅色底和同色系文字，夜间采用低亮度底色。标签按明暗模式校正对比度，原始选择色保留在配置中。
- 标签文字按框内可用空间适配，较长名称会缩小字号并保留边距，不撑大班次框。
- 个人班次和法定「休／班」分别显示，不会互相覆盖，也不会根据节假日自动调班。目前提供固定循环，不提供提醒或单日覆盖。
- 倒班保存在当前脚本私有的 `calendar.shifts.v1` 中，与外观设置分开。

## 桌面小组件

### 小号：今日日卡

左对齐显示红色星期、大号日期，以及三行信息：公历年月、干支生肖年、农历月日。采用固定字号和紧凑排版，不给日期添加红底；公布的休班安排显示在右上角。

### 中号：两周日历

七列两行，第一行为包含今天的一周，第二行为下一周。显示星期、公历日期、农历／节日／节气及休班标记，底部显示今天的完整公历与农历信息。

### 大号：完整月历

七列六行，共42个日期，包含前后月日期。顶部将当前年月与今天的干支生肖年、农历月日合并，用「·」分隔，例如「2026年11月 · 丙午马年 十月初二」。不再显示底部日期行，腾出的空间用于日期行距。

### 配色与标记

- 浅色模式使用白色背景和深色文字；夜间模式使用接近黑色的深色背景和浅色文字。小号保留轻微渐变背景，班次配色独立于整体底色。
- 周六、周日显示灰色；颜色依据真实星期，不随调休改变。
- 中、大号今日红底中的数字及农历保持白色。
- 农历初一显示月份（含闰月）及红色短下划线；其他日期优先节日，其次节气，再次农历。今天优先显示农历。
- 锁屏尺寸显示简化日期文字。

## 农历、节日与节气

支持公历 **1901—2099年**，农历及节气使用离线的 [lunar-javascript](https://github.com/6tail/lunar-javascript) 算法，不需要联网。布局包含超出范围的日期时，小组件提示支持范围。

传统节日包括：春节、元宵、龙抬头、端午、七夕、中元、中秋、重阳、腊八、小年和除夕。

- 小年分别显示北方腊月廿三、南方腊月廿四两种常见日期，并非全国统一习俗。
- 闰月不重复匹配传统节日。
- 除夕按下一天农历年份变化判断，兼容腊月廿九和三十。
- 公历节日包括元旦、劳动节、国庆节；清明按节气日期显示。
- 包含全部24节气：小寒、大寒、立春、雨水、惊蛰、春分、清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至。

「今天」和节气日期以北京时间（UTC+8）为准，不跟随旅行时区。干支生肖年以农历新年为界，不采用立春换年口径。

## 休班数据与离线使用

蓝色「休」表示公布的放假日期，橙色「班」表示公布的调休上班日期。**传统节日和节气不自动等于法定休假；普通周末不自动标「休」，没有标记也不代表工作日。** 单位、地区和个人额外安排不在数据范围内。

2026年安排已核实并内置，首次安装离线也可显示，共33个放假日期、6个调休上班日期：

| 节日 | 放假日期（2026） | 调休上班 |
|---|---|---|
| 元旦 | 1月1—3日 | 1月4日 |
| 春节 | 2月15—23日 | 2月14日、28日 |
| 清明 | 4月4—6日 | 无 |
| 劳动节 | 5月1—5日 | 5月9日 |
| 端午 | 6月19—21日 | 无 |
| 中秋 | 9月25—27日 | 无 |
| 国庆 | 10月1—7日 | 9月20日、10月10日 |

依据：[国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)。

其他年份使用 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 开放数据，成功获取后保存在本地。程序校验年份、日期、休班字段及政府通知来源字段，但不逐次下载政府原文核对。

- **每次运行脚本并打开日历首页，都会联网刷新当前月历涉及年份的假日数据**，不受缓存有效期或失败重试间隔限制；2026年也会检查联网数据。联网成功后更新显示，并请求小组件刷新。
- 浏览其他月份及小组件自身加载仍沿用缓存策略：2026年可使用已核实内置数据，其他年份有效缓存默认7天后尝试重新获取。
- 无数据年份请求失败后，常规加载在24小时内不重复尝试；每次打开首页及设置中的「刷新缓存」不受此限制。
- 请求超时为5秒，跨年分别加载所需年份。
- 网络失败时继续使用有效缓存；无有效数据则不显示对应年份的休班，2026年有内置兜底。
- 不猜尚未公布的安排。农历、传统节日和节气不受网络故障影响。

## 刷新与使用边界

小组件请求北京时间次日00:01刷新，最终刷新时间由 iOS 调度，不能保证整点更新。App 内没有源码更新按钮，也未配置自动源码更新周期。

界面曾结合用户提供的 iPhone 截图调整；不同设备、系统字体、显示缩放及系统着色可能影响布局，不能保证跨设备像素一致。本地类型检查采用官方文档派生的有限声明，不等于完整 iOS 运行验证。农历、节气及内置休班数据的验证依据见 `VALIDATION.md`。

## 隐私与许可

不读取系统日历、定位或个人资料，不上传手机数据。休班联网请求只获取所需年份的公开数据。

项目、农历库及开放假日数据使用 MIT 许可证，相关许可保存在 `LICENSE` 与 `licenses/`。

主要文件：

- `index.tsx`：日历首页、设置及原生预览。
- `widget.tsx`：桌面小组件入口与小号原生布局。
- `calendar.ts`：北京时间、日历规则与外观设置。
- `shifts.ts`：倒班配置、严格校验、独立存储和循环日期计算。
- `shift-settings.tsx`：班次名称、色板与样式、编辑排序、左滑确认删除及返回保存页面。
- `shift-editor.ts`：按列表生成每日循环、结构变更当天起算、旧规则转换、保存校验及会话草稿保留。
- `shift-style.ts`、`shift-badge.tsx`：统一明暗标签配色及原生文字标签。
- `render.ts`：中、大号 SVG 布局及日夜配色。
- `calendar-geometry.ts`：首页与组件共用的今日底形包围和班次条留白规则。
- `home-cell-layout.ts`：首页明确的原生日期/农历坐标、今日底形及班次底色宽度约束。
- `holidays.ts`、`holiday-2026.ts`：休班校验、缓存和内置数据。
- `vendor/lunar.js`：离线农历与节气算法。

开发接口参考：[Scripting 官方文档](https://scriptingapp.github.io/)。
