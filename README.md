# 农历日历 · iPhone Scripting

适用于 iPhone **Scripting**。提供完整月历首页及小号、中号、大号桌面小组件，支持农历、传统节日、24节气和中国大陆休班标记。

## 一键导入

[点击一键导入到 Scripting](https://scripting.fun/import_scripts?urls=["https%3A%2F%2Fgithub.com%2FWangsc1%2Fcalendar"])

在 iPhone 上打开链接，按提示导入。需要先安装 Scripting。

## 安装与使用

1. 在 iPhone 打开导入链接，按提示导入。
2. 在 Scripting 运行 `calendar`，即可打开日历首页。
3. 主屏幕长按 → 添加 Scripting 小组件 → 编辑小组件 → 选择 `calendar`，参数留空。
4. 可选择小号、中号或大号。建议使用系统原色／全彩外观；系统着色模式可能改变配色。

也可创建脚本项目并复制完整仓库源码。项目根目录应直接包含 `script.json`、`index.tsx`、`widget.tsx`，同时保留 `vendor/`、`licenses/` 等依赖文件，无需 npm 构建。

## 日历首页

- 顶部显示今天的公历日期，点击可回到本月并选中今天。
- 月份两侧箭头切换上一月／下一月；在星期栏和日期区域左右滑动也可翻月：左滑下一月，右滑上一月。
- 月历为七列六行，包含前后月日期；星期顺序跟随「每周首日」设置。
- 每格显示公历日期及农历、节日或节气。今天使用红色标记；周末和其他月份日期显示淡色。
- 点击日期，底部显示所选日期的完整公历、干支生肖年、农历月日及相关节日、节气。
- 首页及设置页跟随系统浅色／深色外观。

## 右上角设置

点击首页右上角「⋯」打开设置，版本号显示在「设置」标题右侧。

| 设置 | 功能 |
|---|---|
| 每周首日 | 周一至周日任选，默认周一；影响首页和中、大号小组件的排列 |
| 休班显示 | 蓝色「休」／橙色「班」，或对应颜色的小圆点 |
| 今日显示 | 圆形／圆角方形红底；用于首页及中、大号小组件 |
| 倒班设置 | 编辑已有班次样式、基准日期及对应循环位置，开启后在首页和各尺寸组件显示 |
| 预览组件 | 打开 Scripting 自带预览界面，可在预览中选择尺寸和主题 |
| 刷新缓存 | 主动获取相关年份的休班安排并请求刷新小组件 |

设置保存在当前脚本的私有 Storage，不影响其他脚本。设置变化会请求桌面小组件刷新，实际时机由 iOS 决定。

## 倒班：先配置，再显示

入口：右上角「⋯」→「倒班设置」。默认关闭，仅提供 **白班（蓝）→上夜（红）→下夜（橙）→休息（绿）** 四天模板，**没有预设基准日期或实际排班**。

1. 在「班次设置」编辑已有班次或点「新建班次」。新增项须命名后才可保存，名称须唯一、1—4字，最多12种；新建只增加班次类型，不会自动加入已有循环或设置实际基准。颜色为4行8列的32色色块，选中显示勾号；已有六色配置仍保留，色板外的原颜色单独显示选中块。每个班次可独立选择「普通」或「透明」，并实时预览文字标签。
2. 当前界面不提供循环天位置编辑、拖动排序及添加一天；不会因此清空或重建已有班次和循环。已有任意重复序列（如「白班→上夜→白班→休息」）及多于60天的循环照常读取和计算，不设业务天数上限。
3. 点击「基准日期：请选择日期」（已有日期时显示原日期），在原生月历中点选一个**实际已知**班次的日期并「确认」，再选该日对应的**循环第几天**。日期范围1901—2099年，按北京自然日以`YYYY-MM-DD`保存。同一班次出现多次时，必须按位置区分，不能只选班次名称。未配置时月历默认候选为北京今天，仅打开、浏览、取消或下滑关闭均不会填写日期；只有明确确认才带回草稿。
4. 开启「倒班显示」，使用系统返回按钮或边缘滑动返回；页面消失时自动校验、保存有效修改并请求刷新组件，无需额外点击保存。未修改不重复写入或刷新。保存成功后首页应用，iOS组件刷新可能延迟。

未开启、日期为空或循环位置未选时，均不显示排班，不用今天或某个班次自动补齐。格式错误、空名称、重复名称、无效日期或空循环不保存，并明确提示。已有基准配置时，缺日期或循环位置的修改不能覆盖原排班；首次未配置时可保存格式有效的班次模板，仍不产生排班。保存失败或校验不通过时保留原配置，草稿在本次打开期间保留，重新进入倒班设置可修正或重试。

- 基准日前使用同一循环倒推，跨月、跨年、闰日均按自然日连续计算，不受设备时区或夏令时影响。
- 在班次行**向左滑动**后点删除并确认，会从草稿循环中移除该班次的**全部引用**；若改变循环，必须重新选择基准位置才能保存到已有排班。最后一个班次不能删除；若删除会使整个循环为空，也会提示并保留原班次和排班，避免无法保存的草稿。重命名、改颜色或样式不会改变位置。
- 「普通」为实色底白字；「透明」为浅色底与同色系不透明文字，夜间使用低亮度色底。仅背景作预混合，不对整张标签或文字降低透明度；浅色会作同色系明暗校正，确保标签文字对比度至少4.5:1。原始选择色仍原样存储，旧数据缺少样式时默认普通。首页、日期详情、各尺寸组件与设置预览共用配色规则。
- 日期选择使用官方 `DatePicker` 的 `graphical` 月历，以系统弹层呈现，不是自造网页；外观和年月切换等交互由iOS/宿主决定，不保证与Safari截图逐像素相同。月历候选与设置草稿隔离，弹层遮盖设置时不触发提前保存；关闭后仍需返回设置页的上一层才按原规则保存和刷新。选择器仅使用本地年月日载体，毫秒时间戳不写入排班配置，不按UTC截取日期。
- 自动保存使用官方 `onDisappear` 页面生命周期；不是可拦截的导航回退事件。系统返回及完成的边缘返回由宿主页面消失回调覆盖；其他实际页面消失也可能触发保存。无法拦截强制退出或宿主未发送的回调，不保证进程被杀前保存。
- 首页日期格下方显示彩色班次标签，底部所选日期详情同时显示班次。首页使用49点高的原生日期格，日期18/农历10点字号不变，以12点目标基线差明确定位、紧凑排列；今日红底固定约38.71点，不再由原生文字块行高推大。首页班次底色作为独立原生形状，背景本身明确设置为实际格宽减10点（两侧各5点），不依赖文字自然宽或背景修饰器顺序；圆/方今日与点击选择保持。实际视觉仍需iPhone验收，不将本地模型当作真机一致保证。小号组件在大日期旁显示11点字号、40×19点标签；中、大号在日期格中增加一行标签，仅在启用排班时收紧格内农历行距。大号年月到星期的空隙收紧7点，回收空间等分给5处日期行间隔，每处增加1.4点，末行及完整日期农历页脚位置不变；格内间隔不加大。锁屏文字也附带班次名称。
- 个人班次与法定「休／班」是两套独立信息，不会互相覆盖，也不会根据节假日自动调班。仅提供固定循环，不提供提醒或单日覆盖。
- 倒班使用独立私有 Storage 键 `calendar.shifts.v1`，不迁移或覆盖已有外观设置。读取失败或坏配置会停止显示排班，设置页提示原因，不自动改写存储；保存失败不应用修改、不请求刷新。Storage成功返回表示已接收写入，系统实际落盘仍由宿主负责。

## 桌面小组件

### 小号：今日日卡

左对齐显示红色星期、大号日期，以及三行信息：公历年月、干支生肖年、农历月日。采用固定字号和紧凑排版，不给日期添加红底；公布的休班安排显示在右上角。

### 中号：两周日历

七列两行，第一行为包含今天的一周，第二行为下一周。显示星期、公历日期、农历／节日／节气及休班标记，底部显示今天的完整公历与农历信息。

### 大号：完整月历

七列六行，共42个日期，包含前后月日期。顶部显示当前年月，底部显示今天的完整日期；日期字号、加粗方式和农历间距与中号采用相同规则。

### 配色与标记

- 浅色模式使用白色背景和深色文字；深色模式使用深灰背景和浅色文字。小号使用轻微渐变背景。
- 周六、周日显示灰色；颜色依据真实星期，不随调休改变。
- 中、大号今日红底中的数字及农历保持白色。
- 农历初一显示月份（含闰月）及红色短下划线；其他日期优先节日，其次节气，再次农历。今天优先显示农历。
- 锁屏尺寸显示简化日期文字。

## 农历、节日与节气

支持公历 **1901—2099年**，农历及节气使用离线的 [lunar-javascript](https://github.com/6tail/lunar-javascript) 算法，不需要联网。布局包含超出范围的日期时，小组件提示支持范围。

传统节日包括：春节、元宵、龙抬头、端午、七夕、中元、中秋、重阳、腊八、小年和除夕。

- 小年分别显示北方腊月廿三、南方腊月廿四两种常见日期，并非全国统一习俗。
- 闰月不重复匹配传统节日。
- 除夕按下一天农历年份变化判断，兼容腊月廿九和三十。
- 公历节日包括元旦、劳动节、国庆节；清明按节气日期显示。
- 包含全部24节气：小寒、大寒、立春、雨水、惊蛰、春分、清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至。

「今天」和节气日期以北京时间（UTC+8）为准，不跟随旅行时区。干支生肖年以农历新年为界，不采用立春换年口径。

## 休班数据与离线使用

蓝色「休」表示公布的放假日期，橙色「班」表示公布的调休上班日期。**传统节日和节气不自动等于法定休假；普通周末不自动标「休」，没有标记也不代表工作日。** 单位、地区和个人额外安排不在数据范围内。

2026年安排已核实并内置，首次安装离线也可显示，共33个放假日期、6个调休上班日期：

| 节日 | 放假日期（2026） | 调休上班 |
|---|---|---|
| 元旦 | 1月1—3日 | 1月4日 |
| 春节 | 2月15—23日 | 2月14日、28日 |
| 清明 | 4月4—6日 | 无 |
| 劳动节 | 5月1—5日 | 5月9日 |
| 端午 | 6月19—21日 | 无 |
| 中秋 | 9月25—27日 | 无 |
| 国庆 | 10月1—7日 | 9月20日、10月10日 |

依据：[国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)。

其他年份使用 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 开放数据，成功获取后保存在本地。程序校验年份、日期、休班字段及政府通知来源字段，但不逐次下载政府原文核对。

- 有缓存时优先使用；其他年份缓存默认7天后尝试重新获取。
- 无数据或请求失败时，默认24小时内不重复尝试；主动刷新不受此限制。
- 请求超时为5秒，跨年分别加载所需年份。
- 网络失败时继续使用有效缓存；无有效数据则不显示对应年份的休班，2026年有内置兜底。
- 不猜尚未公布的安排。农历、传统节日和节气不受网络故障影响。

## 刷新与使用边界

小组件请求北京时间次日00:01刷新，最终刷新时间由 iOS 调度，不能保证整点更新。App 内没有源码更新按钮，也未配置自动源码更新周期。

界面曾结合用户提供的 iPhone 截图调整；不同设备、系统字体、显示缩放及系统着色可能影响布局，不能保证跨设备像素一致。本地类型检查采用官方文档派生的有限声明，不等于完整 iOS 运行验证。农历、节气及内置休班数据的验证依据见 `VALIDATION.md`。

## 隐私与许可

不读取系统日历、定位或个人资料，不上传手机数据。休班联网请求只获取所需年份的公开数据。

项目、农历库及开放假日数据使用 MIT 许可证，相关许可保存在 `LICENSE` 与 `licenses/`。

主要文件：

- `index.tsx`：日历首页、设置及原生预览。
- `widget.tsx`：桌面小组件入口与小号原生布局。
- `calendar.ts`：北京时间、日历规则与外观设置。
- `shifts.ts`：倒班配置、严格校验、独立存储和循环日期计算。
- `shift-settings.tsx`：已有班次名称/色板/样式、左滑删除及基准日期/循环位置的编辑页面。
- `shift-editor.ts`：返回保存校验、无变更去重与会话草稿保留。
- `shift-date-picker.tsx`：原生月历候选/确认取消与北京自然日到选择器本地年月日的双向转换。
- `shift-style.ts`、`shift-badge.tsx`：统一明暗标签配色及原生文字标签。
- `render.ts`：中、大号 SVG 布局及日夜配色。
- `calendar-geometry.ts`：首页与组件共用的今日底形包围和班次条留白规则。
- `home-cell-layout.ts`：首页明确的原生日期/农历坐标、今日底形及班次底色宽度约束。
- `holidays.ts`、`holiday-2026.ts`：休班校验、缓存和内置数据。
- `vendor/lunar.js`：离线农历与节气算法。

开发接口参考：[Scripting 官方文档](https://scriptingapp.github.io/)。
