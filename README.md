# 双周农历日历 · iPhone Scripting

**版本 1.4.7。这是 Scripting 项目，不是 Scriptable 脚本。** 中号显示包含今天的一周及下一周，共7列、两行；每周开始可选周一至周日，默认周一；固定深灰底。按北京时间（UTC+8）确定“今天”，不跟随旅行时区。

## 安装与使用

### 本地源码包（无需GitHub）

1. 将 `calendar-1.4.7.zip` 保存到 iPhone“文件”，解压得到 `calendar` 文件夹。
2. 在 Scripting 中创建名为 `calendar` 的脚本项目，将解压后的**全部文件及子目录**导入/复制到该项目目录。不要只粘贴 `widget.tsx`：`vendor/lunar.js`、数据模块、许可证都必须保留。目录根部应直接包含 `script.json`、`index.tsx`、`widget.tsx`，不要多套一层 `calendar/calendar`。
3. 如果你的 Scripting 版本提供本地ZIP导入，可以直接尝试导入本包；不同版本入口名称可能不同。本次未在iPhone验证ZIP导入交互。手动创建项目并复制源码是离线备用方法，不需要 npm 或联网构建。
4. 在 Scripting 内运行“**双周农历日历**”（内部名 `calendar`），打开黑色分组设置页，点击蓝色“预览小组件”。
5. 主屏幕长按 → 添加 **Scripting** 中号小组件 → 编辑小组件 → 选择 `calendar` / 双周农历日历。参数留空即可。建议使用iOS原色/全彩外观；系统着色模式可能改变参考配色。

## 分组设置

App内使用官方List/Section的黑色背景、深灰圆角分组卡，去掉长说明、来源串和双周明细；完整说明留在本README。版本号显示在“高级”标题同一行右侧。高级分组包含：

- **每周首日**：仍可从周一至周日7项单选，默认周一；双周第一行始终包含今天，第二行为下一周。周六/周日按真实星期灰色，不按列位。
- **休班显示**：字=蓝色“休”/橙色“班”；点=对应蓝/橙小圆点。只标确切公布安排，不把普通周末画成休假点。
- **今日显示**：周/月卡采用红色圆底或圆角方底，日期数字bold；小号日卡按目标图左对齐常规字重，不应用圆/方高亮。
- **重置所有设置**：先弹官方确认框，可取消；确认仅恢复本脚本外观/周首日默认值，不清假日缓存，不动其他脚本数据。

主设置页蓝色“预览小组件”按钮保留Scripting原生Widget.preview（默认中号）。1.3.0已删除“小组件自定义”入口、编辑整页、字号Stepper及App静态实时卡，不再提供日/周/月编辑界面。

小号采用固定设计，不读取遗留 `fonts.day` 字号；不清除Storage。中/大号继续读取已有字号及外观设置，未改变其显示。

外观保存到当前脚本私有Storage的 `calendar.appearance.v2`。从1.1.0更新时，在新外观没有周首日值的情况下读取旧 `calendar.weekStart.v1`，保留任意周首日；首次保存才写新外观对象。缺失/无效配置回默认，保存失败弹短提示并保留旧界面。重置写新默认值，会覆盖旧首日效果而不删除缓存。

设置变化会请求桌面刷新，iOS可能延迟。跨年数据按对应日/双周/月范围加载，无数据不猜休班。错误与数据刷新结果用官方Dialog短反馈，不在设置页堆成长文字；“数据”分组保留刷新假日缓存，这是休班数据刷新，不是源码更新。

## 外观和标记

- 周一至周五白色，周六周日灰色；颜色按星期划分，不随调休改变。
- 周/月今天：可选红色圆底/圆角方底，日期白色加粗，下方农历标签也在红底内。
- 小号以IMG_4558右侧Calunar卡为新参考：完整方卡约10.2%左内距，红色medium星期、白色regular大日期，底部白色“公历年月／干支生肖年／农历月日”三行；上浅下深#363636→#262626渐变，无红底，无重复农历日。实际节日/节气可保留短行。固定比例字号随完整组件尺寸缩放，旧用户日卡字号不再影响显示。1.3.1起小号改用Scripting原生Text/VStack排版和系统默认小组件边距，不再使用SVG绘制，避免内容被二次缩放；日期在星期与底部三行之间由等分Spacer垂直居中。
- 官方文档没有公开WidgetKit禁用contentMargins接口。本版用完整displaySize固定frame、零padding及官方ignoresSafeArea，避免脚本再缩小内容；系统是否仍施加额外margin及最终字形须手机新截图确认，不能承诺跨系统像素一致。
- 日期右上角：蓝色“休”（或蓝点）为国务院公布的放假日期，橙色“班”（或橙点）为公布的调休上班日期。**普通周末不自动标“休”；没有标记不代表没有休假，也不代表是工作日。** 单位、地区或个人额外安排不在此数据范围。
- 格子今天优先显示农历；农历初一显示月份（含闰月）及红色短下划线；其他日期优先节日，其次节气，再次农历日期。同日多项信息按上述优先级显示，不再提供设置页长串日期明细。
- 周/月底部完整公历日期、以农历新年为界的干支生肖年、农历月日。例如：`2026年10月9日 丙午马年 八月廿九`，不使用八字立春换年的口径。
- 小号=今日日卡；中号=原双周7列2行；大号=当前月7列6行42格（含前后月日期，灰色区分）；表头全部写“周一”至“周日”，按周首日排序。锁屏仍简化文字。

## 农历、节日及支持年份

- 产品支持公历 **1901—2099** 年的农历及24节气，全部离线计算，采用成熟的 **6tail/lunar-javascript 1.7.7**（寿星天文算法）。当前布局含日期超出边界时显示范围提示，不猜越界农历。
- 传统节日：春节、元宵（正月十五）、龙抬头（二月初二）、端午（五月初五）、七夕（七月初七）、中元（七月十五）、中秋（八月十五）、重阳（九月初九）、腊八（腊月初八）、小年（北方腊月廿三／南方腊月廿四）、除夕。
- 闰月不重复匹配这些节日。小年地域习惯并不完全一致，此处并列提供两种常见日期；不代表全国统一节日/休假。
- 除夕按“下一天农历年变化”判断，兼容腊月廿九和三十，不硬编码公历年份或腊月三十。
- 公历节日另显示元旦、劳动节、国庆节。清明以节气日期显示。
- 全部24节气：小寒、大寒、立春、雨水、惊蛰、春分、清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至。只显示北京时间日期，不显示交节时刻。
- 不收集全部宗教、民俗、地方或国际纪念日；以上即本项目明确支持范围。**传统节日和节气绝不自动等同于法定休假。** 算法支持范围不等于每年均有官方休班数据。

## 法定休班数据与离线边界

**2026年已核实并内置，首次安装完全离线也有休班。** 共39条：33个放假日期、6个调休上班日期。对应国务院办公厅《2026年部分节假日安排的通知》，国办发明电〔2025〕7号（2025-11-04）：

|---|---|---|
| 元旦 | 1月1—3日 | 1月4日 |
| 春节 | 2月15—23日 | 2月14日、28日 |
| 清明 | 4月4—6日 | 无 |
| 劳动节 | 5月1—5日 | 5月9日 |
| 端午 | 6月19—21日 | 无 |
| 中秋 | 9月25—27日 | 无 |
| 国庆 | 10月1—7日 | 9月20日、10月10日 |

官方通知：https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm

开放数据：https://github.com/NateScarlet/holiday-cn （MIT）；运行时只向 `raw.githubusercontent.com/NateScarlet/holiday-cn/master/年份.json` 请求对应日/双周/月布局所需年份。无个人信息、定位或日历权限，也不上传手机数据。

- 2026年默认直接读取核实内置/缓存；数据分组“刷新假日缓存”可主动刷新。其他年份**不承诺已有完整安排**：只使用上述开放数据的对应年份，要求年份、日期、休班布尔值、无重复日期及中国政府网通知来源字段有效，成功后保存到当前脚本私有 `Storage`。
- 其他年份有缓存时默认7天内不重取；缺数据/请求失败默认24小时内不重复尝试。主动刷新不受此限制。每次联网请求5秒超时；跨年独立处理两年的数据。
- 网络失败：有有效缓存则继续使用，没有则不显示该年的任何休/班。2026年始终有内置兜底；农历、传统节日和节气不依赖网络，不受假日数据失败影响。
- 损坏缓存不会被用来生成标记。通知来源校验是结构性校验，不是逐次下载政府原文验证；2026全39条已另外对照官方原文核实。此项目不使用农历库自带休假推断，也不猜尚未公布的安排。

## 刷新及真机验证边界

小组件请求北京时间次日00:01更新，最终时机由iOS控制，不能保证整点即时刷新。外观设置变更、重置或假日数据刷新会请求Widget刷新，同样不保证立即执行。用户已提供此前版本的真实截图，1.3.0按新左右对照调整；修正后的SVG中文字体、完整容器覆盖、主屏幕着色及午夜刷新仍待手机验证，没有提供或冒充本版真机截图。

本地已通过：对照香港天文台2025/2026共730天农历和48节气；全支持年份闰月不误标传统节日；春节跨农历年除夕、周一跨月跨年、北京时间跨午夜；2026全39条休班；离线/损坏缓存/无数据不虚构；旧版本曾验证源码更新校验/回滚（1.2.1已移除此功能）。严格TypeScript检查使用从官方文档提取的有限接口声明（没有iPhone同步的完整官方 `.d.ts`），另做TSX/JS解析与依赖打包检查；不等于完整Scripting运行时类型或iOS验证。1.1.0另验证7种开始日、跨年范围、表头/真实周末、默认及无效Storage、同一设置读取路径；没有重跑此前已充分验证的农历全范围对照。1.2.0增量验证覆盖默认/迁移/字号范围、字点圆方、日双周月布局、42格跨年及前后月灰色、实时编辑/原生预览绑定、重置确认/取消保留缓存、受影响TS类型及清单摘要；没有重跑此前农历全年权威比较。1.2.1仅检查UI删减、版本标题位置、保留设置/预览/数据刷新、受影响TS接口及归档一致性；未重跑日历测试。1.2.2小号布局增量检查包括普通日期三行左对齐、字号/长农历边界和共享渲染路径；中大号56组同输入SVG与1.2.1字节完全一致。1.3.0定点检查App入口删除、小号固定字号/比例与中大号同输入不变；本版未做真机像素级验证。详见 `VALIDATION.md` 的分版本历史记录。
